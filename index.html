          GitHub Pages Setup

          To host this wiki on GitHub Pages and let collaborators edit:

          1. Create a new GitHub repository (e.g. my-lore-wiki)
          2. Download this HTML file and name it index.html
          3. Export your data JSON and name it wiki-data.json
          4. Push both files to the repo's main branch
          5. Go to Settings → Pages and set source to main / root
          6. Your wiki is now live at https://username.github.io/my-lore-wiki/
          7. To update: export JSON → commit wiki-data.json → push
          8. Collaborators can edit locally with the edit code, then export and submit a PR

          For real-time multi-user editing, consider adding a GitHub Actions workflow that auto-commits the JSON. Advanced users can hook the Export button to the GitHub API directly.
