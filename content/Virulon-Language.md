## Alphabet

The Virulon script transliterated into English letters, with pronunciations. Virulon has no equivalent of **D**.

| English | Virulon | Pronounced |
|---|---|---|
| A | Dy | DOO |
| B | Ln | LUN |
| C | Cet | SET |
| D | *none* | |
| P | PH | Feh |
| R | Ruh | Rue |
